## Architecture

```
chatbot/
├── __init__.py       # Package init
├── config.py         # Env-var config (fully standalone)
├── memory.py         # SessionMemory (SQLite sliding window)
├── prompts.py        # French SLM prompts (self-contained)
├── service.py        # ChatService (wraps AgenticRagService when available)
├── cli.py            # Interactive REPL + one-shot CLI
└── api.py            # FastAPI web API
```

## Configuration

All config is via environment variables (see chatbot config module for defaults).

Key settings:
- `LLM_PROVIDER` = `openrouter` | `ollama`
- `LLM_MODEL` — router model (default: `qwen/qwen3-14b`)
- `SYNTH_MODEL` — synthesis model (default: `qwen/qwen3-8b`)
- `OPENROUTER_API_KEY` — required for cloud LLMs
- `QDRANT_URL` — vector store URL (default: `http://localhost:6333`)
- `EMBED_PROVIDER` = `openai` | `ollama`
- `CHAT_MAX_HISTORY` — turns to keep per session (default: 10)

## API Reference

| Method | Path | Description |
|--------|------|-------------|
| GET    | `/` | HTML landing page |
| GET    | `/api/health` | Health check (`rag_available` field shows RAG status) |
| GET    | `/docs` | Swagger UI |
| GET    | `/redoc` | ReDoc docs |
| POST   | `/api/chat/ask` | One-shot Q&A (body: `{question, session_id?}`) |
| POST   | `/api/chat/stream` | SSE streaming response |
| GET    | `/api/chat/sessions` | List active sessions |
| GET    | `/api/chat/stats?sid=<id>` | Session statistics |
| POST   | `/api/chat/clear?sid=<id>` | Clear session history |

## CLI

```bash
# Interactive REPL
python -m chatbot.cli

# One-shot
python -m chatbot.cli -q "Qu'est-ce que la délégation efficace ?"

# Named session (multi-turn)
python -m chatbot.cli --session my_coaching -q "Qu'est-ce que la délégation ?"
python -m chatbot.cli --session my_coaching -q "Comment motiver mon équipe ?"

# Ephemeral (no disk persistence)
python -m chatbot.cli --no-persist

# Streaming output
python -m chatbot.cli --stream -q "Quels sont les 5 principes ?"
```

## Deploying to a Server

### Option 1: uvicorn directly
```bash
pip install fastapi uvicorn httpx pydantic
pip install llama-index-core llama-index-llms-openrouter llama-index-embeddings-openai qdrant-client
export OPENROUTER_API_KEY=sk-or-v1-...
uvicorn chatbot.api:app --host 0.0.0.0 --port 8788 --workers 2
```

### Option 2: Docker
```bash
docker build -t activiity-chatbot .
docker run -p 8788:8788 -e OPENROUTER_API_KEY=sk-or-v1-... activiity-chatbot
```

See `deploy/` directory (if provided).
